Developed a Hospital Management System using SQL to manage hospital operations and maintain structured patient records. 
The project includes six tables: Patients, Doctors, Departments, Appointments, Prescriptions, and Payments.

Implemented database operations using CREATE, INSERT, SELECT, UPDATE, DELETE, WHERE, ORDER BY, GROUP BY, HAVING, aggregate functions, joins, and subqueries.

Used Primary Keys and Foreign Keys to establish relationships between tables and maintain data integrity. Practiced simple, intermediate, 
and advanced SQL queries to retrieve meaningful information, analyze hospital records, track appointments, and manage payment details.
